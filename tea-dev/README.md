# technoEconomicAnalysis
This repository is intended to show the progress and examples of a Techno-Economic Analysis (formerly Manufacturing Process Design Optimization) ontology

The TEAOntology.ttl (and .rdf) is the current version of the ontology.  It imports the following ontologies:
- the Basic Formal Ontology (BFO)
- the Industrial Ontologies Foundry (IOF)
- the IOF Biopharmaceutical Manufacturing Ontologies, namely Equipment, Manufacturing Execution, Material, Monitoring & Control, Parameter, Physical and Recipe modules.

With these imports, the TEA Ontology utilizes the Recipes and Manufacturing Execution modules, along with Material, to describe biological methods for producing Acetic Acid with different Acetobacter bacteria. An Advances in Production Management Systems (APMS) conference paper was written for and presented at the APMS 2025 conference in Kamakura, Japan (https://www.apms-conference.org/past-conferences/apms-2025/). DOI: 10.1007/978-3-032-03550-9_28.

In addition, work has been done to extend previous work to refactor the ontology for TEA and focus on sensitivity analysis. The TEA ontology itself has been fully annotated with IOF annotation standards. At this time a paper is being written on that work.

These files and this README will be updated as extensions to the ontology are performed.
